What is real? The native Altinn App, Keycloak OAuth2 client credentials, signed JWT validation, agency-specific roles, per-service mutual TLS certificates, purpose-restricted registry access, separate Docker networks, agency-owned audit logs and a retryable outbox. What is not real? NepalID, actual government registries, actual Nagarik mobile App, a nationwide deployment, or independently operated Altinn national Authentication / Authorization / Storage services.

Who can talk to whom?

CITIZEN CHANNEL
📱 Nagarik App — mobile todayNot connected here. A government-approved future web channel could use the same back-end interfaces.
ACTUAL ALTINN APP
⚙ Altinn Apps .NET runtimeGenuine forms, BPMN and XACML running against official LocalTest service emulators.
TRUST / IDENTITY
🔑 Keycloak OIDCMachine-to-machine OAuth2 access tokens are signed and checked by resource gateways; all identities are fictional.
↓ Shared broker → agency-authorized service calls only ↓
SHARED EXCHANGE NETWORK
🏛 Government exchange brokerObtains a machine token, connects to a gateway with mutual TLS, records correlated requests and queues events for retry.
SERVICE ACCESS BOUNDARY
🔐 Agency gatewayChecks JWT issuer, audience, expiry, declared purpose and agency permission; requires a valid TLS client certificate. Only its gateway enters its private registry network.
AUDIT & DELIVERY
📝 Trace + durable outboxEach request gets a correlation ID; notification events are queued and retried if the destination is unavailable.
↓ Each gateway alone can enter its own internal data network ↓
TRANSPORT PRIVATE NETWORK
🚘 Department of TransportOwn gateway + isolated mock licence database. No connection to civil or company database networks.
CIVIL PRIVATE NETWORK
🪪 Public/civil registryOwn gateway + isolated fake resident record store; query signing and replay detection.
COMPANY PRIVATE NETWORK
🏢 Office of Company RegistrarOwn gateway + isolated synthetic company records. No agency publishes its data store to the host.

A Docker bridge network represents a logical security zone here. In real government deployments, these may be different departments, cloud accounts, data centres, sites, VPN endpoints, firewalls and separately governed environments.

How this maps to real government

Identity: a government-approved identity federation and service registration.

Exchange: an audited API gateway or service mesh with controlled network links.

Agency: remains data controller, sets access policy and owns its data.

Results: notifications delivered to approved mobile/web channels with consent and retention rules.
